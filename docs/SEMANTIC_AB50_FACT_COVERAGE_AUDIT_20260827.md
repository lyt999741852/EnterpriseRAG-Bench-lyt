# Experiment A：AB50 原子事实—检索阶段漏斗审计

日期：2026-08-27
范围：`pageindex_ab50_semantic_conflict_guard_r3_20260826` 的 50 题 no-correction 结果。
性质：离线诊断；没有修改线上 pipeline、路由、候选池或索引。

## 目的与口径

本实验不再只看“期望文档是否出现”，而是把题库中的官方 `answer_facts` 逐条映射到冻结运行的阶段：

`raw_views → pre_rerank → post_rerank → final_before_generation → submitted`。

事实支持使用期望文档正文上的确定性词法重叠指标（含数字锚点）作为筛查信号，不将其当作语义蕴含或官方评分。`expected_doc_ids` 和 `answer_facts` 仅在运行结束后使用；线上链路没有读取这些字段。

本地语料命中了 73 个本实验所需的期望文档。3 条题目没有期望文档，另有部分官方事实与源文档存在同义改写，因此“无词法支持”不能直接等同于语料缺失；这部分单独保留为审计限制。

## 汇总结果

| 阶段 | 有词法支持的事实数 | 占 211 条官方事实 |
|---|---:|---:|
| raw views | 169 | 80.1% |
| pre-rerank | 164 | 77.7% |
| post-rerank | 150 | 71.1% |
| final before generation | 135 | 64.0% |
| submitted | 112 | 53.1% |

在 211 条事实中，181 条至少在一个期望文档上获得词法支持；按“首次丢失阶段”统计：

| 首次丢失 | 事实数 | 含义 |
|---|---:|---|
| raw views | 12 | 原始混合候选没有保留支持事实的期望文档 |
| pre-rerank | 5 | RRF/候选合并阶段丢失 |
| post-rerank | 14 | reranker 截断或重排后丢失 |
| final before generation | 18 | PageIndex/selector 最终选择丢失 |
| submitted | 23 | 最终上下文有证据，但引用/提交集合未保留 |
| answer generation | 109 | 支持文档已进入 submitted，问题在答案表达、覆盖或评分对齐 |
| 无词法支持/无本地期望文档 | 30 | 仅作诊断限制，不归因于检索阶段 |

## 与 R1/R6/R7 的交叉核对

R1 的 5 个核心 semantic raw-miss（`qst_0116`、`qst_0184`、`qst_0231`、`qst_0251`、`qst_0298`）在本漏斗中仍全部表现为 raw 阶段无目标文档；这不是生成提示词造成的丢失。额外 3 个 `raw_miss` 桶来自没有官方期望文档的题目，不应与 semantic raw-miss 混为一谈。

R6 已证明这 5 个目标文档存在于 BGE 索引，但原题 dense/BM25 top-200 均未命中；R7 的题干派生词法锚点也只恢复 `qst_0231`。本次事实漏斗因此支持“原始候选召回/表示相关性不足”这一结论，但不能支持“只增加 rewrite 或固定关键词”就能普遍解决。

## 关键题目定位

| 题目 | 漏斗观察 | 诊断含义 |
|---|---|---|
| `qst_0116`、`0184`、`0231`、`0251`、`0298` | 支持事实在 raw 即为 0 | 优先研究通用候选覆盖：原题、受约束表示、dense/BM25 union；不先改生成 prompt |
| `qst_0050` | 3/3 事实在 raw 有支持，pre-rerank 后为 0 | RRF/候选预算或合并规则导致丢失，不能归因于 embedding 覆盖 |
| `qst_0093` | 目标文档进入 raw，但官方事实与本地正文词法不对齐；文档层仍在 rerank 后丢失 | 需要同时保留文档级信号与事实级信号，避免只用词法分数下结论 |
| `qst_0041`、`0197`、`0447` | 事实在 post-rerank 仍有支持，final 变为 0 | selector/PageIndex 选择层是独立瓶颈，不能用扩大 raw 候选替代 |
| `qst_0241`、`0280`、`0390`、`0413` | final 仍有事实支持，submitted 变为 0 | 引用/提交保留策略丢证据；可放宽额外文档，但不能丢目标证据 |
| `qst_0356` | 4 条事实到 final，submitted 仅 3 条 | 多文档/多跳证据在最终提交阶段被压缩 |
| `qst_0362` | 13 条事实到 submitted，但 completeness 仅 30.77% | 证据已经在上下文，继续调召回的边际收益低，应单独审查生成覆盖/答案组织 |

## 结论

1. R1 的分桶结论得到事实级证据支持：raw-miss、rerank、selector、submitted 和 generation 是可区分的损失层。
2. 当前最大可操作方向不是继续细化某几道题的 prompt，而是建立一个通用、可托底的候选覆盖漏斗：对原题和受约束查询做候选 union，保留文档级命中，再由后续 rerank/selector 控制成本。
3. 事实级词法指标只能作为离线定位工具。对同义改写事实（例如 `qst_0093`）必须同时报告文档级阶段命中，不能把“词法未匹配”误判成 embedding 或索引缺失。
4. 路由优化应后置于候选覆盖：先确保 semantic 题在不依赖题型锁定的情况下有稳定通用召回，再用规则优先、LLM 低置信回退的路由减少误判；路由正确但候选为空没有收益。

## 下一步实验建议（R11.B）

基于本实验，下一实验只改变 raw candidate representation，不改变 selector、生成 prompt 或评分：

- 为 semantic 查询构造结构化但不含答案的表示（实体、事件、约束、时间/因果关系）；
- 与原题 dense、BM25 结果做低权重 union，而不是替换原题；
- 使用文档级去重和每文档 chunk 上限，保留原题候选作为托底；
- 先在 5 个核心 raw-miss 加控制题做只读 smoke，要求 raw 命中提升且控制题无回退，再决定是否进入 AB50。

该实验不预设答案、不锁定额外文档，也不把单题关键词规则直接接入主链。
