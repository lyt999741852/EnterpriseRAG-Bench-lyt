# 历史归档说明

本目录保存被新的入口、状态或计划替代的材料；文件不删除，以便审计和复现历史决策。

| 子目录 | 内容 | 使用规则 |
|---|---|---|
| `status/` | 已过期的状态入口 | 不作为当前决策依据 |
| `handoffs/` | 历史交接稿 | 仅用于恢复当时上下文 |
| `plans/` | 已结束或已被更新的优化计划 | 仅用于追溯任务演进 |
| `ledgers/` | 截止日期明确的历史测试/优化台账 | 不能替代最新实验汇总 |
| `architecture/` | 已被更新架构说明替代的图文快照 | 仅用于历史对照 |
| `reports/` | 早期阶段报告 | 以最新有效汇总解释其适用范围 |
| `restricted/` | 含历史敏感信息的本地材料 | 仅本地审计，不纳入移交范围 |

当前入口见 [docs/README.md](../README.md)。
