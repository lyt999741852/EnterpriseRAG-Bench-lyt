# Conan 448/32 + DPV4 50 题 no-correction 评测

日期：2026-08-28  
目的：在上一轮 BGE+DPV4 结果基础上，仅切换到预构建 Conan 448/32 数据集及其 1792 维 embedding，观察检索证据覆盖和端到端答案变化。

## 实验条件

- 固定题集：与 `pageindex_balanced50_bge_rerank_question_only_llm_route_multiview_dpv4_20260828` 完全相同的 50 题。
- LLM：`deepseek-v4-flash`（10.72.100.29:18380/v1），温度 0，`enable_thinking=false`，max_tokens 8192。
- 评测：同一 DPV4 judge，`--no-correction`，并发 4；未使用 correction，结果不可与 correction 运行直接比较。
- 向量数据：只读 Elasticsearch `enterprise-rag-qwen3-emb-v3-conan448`，3,030,317 条，`embedding` 维度 1792。
- chunk/embedding 契约：`langchain_conan_recursive`，448/32，OpenAI-compatible embedding `embedding`，维度 1792。
- 检索：沿用 BGE+DPV4 的 hybrid、rewrite/answer-intent、multi-view、remote reranker（candidate 120/top 30）和 PageIndex；仅增加 Conan 分区所需的 `collapse_recursive_partitions=true`。
- 索引策略：`read_existing_index=true`、`overwrite_index=false`，未重建索引。

配置文件：`configs/eval_pageindex_balanced50_conan448_rerank_question_only_llm_route_multiview_dpv4_20260828.yaml`  
结果目录：`outputs/pageindex_balanced50_conan448_rerank_question_only_llm_route_multiview_dpv4_20260828/`

## 总体结果

| 指标 | BGE+DPV4 | Conan448+DPV4 | 变化 |
|---|---:|---:|---:|
| correctness | 68.00% | 68.00% | 0.00 pp |

pipeline 的 simple 指标也为 recall 64.8、invalid 0.1，与 judge 结果一致。

## 分题型变化

- semantic：correctness 58.33% → 50.00%，recall 66.67% → 50.00%，是主要回退来源。
- basic：correctness 不变 72.22%，recall 不变 72.22%，但 completeness 80.19% → 67.69%。
- project_related：correctness 不变 50%，completeness 56.95% → 62.82%，但 recall 39.58% → 23.61%。
- intra_document_reasoning：75% → 100%，说明 Conan 分区对部分同文档推理题有帮助。
- conflicting_info：100% → 50%，需要后续检查冲突证据的召回/排序。
- constrained、miscellaneous、info_not_found 基本不变；high_level 从 0% → 100%（仅 1 题，不能据此泛化）。

两轮 correctness 共 12 题发生翻转：6 题由错变对、6 题由对变错，因此总体 correctness 恰好持平；Conan 没有带来净正确率提升。典型改善包括 qst_0022、qst_0116、qst_0322、qst_0362；典型回退包括 qst_0082、qst_0112、qst_0272、qst_0291、qst_0341。

## 结论与后续建议

1. 在 DPV4、no-correction 和同一 50 题下，Conan 448/32 没有提升 correctness；combined 的小幅上升来自个别题 completeness 改善，不代表检索整体变强。
2. Conan 的主要问题仍是 semantic/project_related 的证据召回下降，尤其出现“答案声明无证据”的题，优先级高于继续微调答案提示词。
3. 下一步应做 raw-miss 证据审计：逐题对比 BGE 与 Conan 的 top-k、rerank 前后候选、PageIndex fallback 和最终保留 chunk，区分“Conan 索引未召回”与“召回后被过滤/路由丢弃”。
4. 在得到 raw-miss 归因前，不建议直接把 Conan 切换为主线；BGE+DPV4 仍是当前可追溯基线。所有后续实验继续使用独立配置、固定题集和 no-correction，避免混入 correction 变量。
