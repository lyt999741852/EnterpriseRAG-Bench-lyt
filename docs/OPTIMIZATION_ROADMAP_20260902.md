## 当前优先级

1. **先验证 O4.P3**：它已有 F500 正向结果，但必须将“候选主线”与“正式冻结基线”区分。
2. **再处理 Semantic raw-miss**：按查询表示、候选池、rerank、admission、生成五层定位；不使用题型标签或 gold 文档在线硬编码。
3. **处理 Project/Completeness**：优先文档聚合、覆盖与引用保留；任何策略必须是 append-only，并保留原题 BM25+dense 候选。
4. **最后才考虑替代 embedding / 全库重建**：仅在隔离 Recall@K、索引覆盖、延迟与成本都稳定优于 BGE 时立项。
