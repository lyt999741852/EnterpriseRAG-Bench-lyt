评分、日期和配置必须能回溯到对应的 Markdown、YAML 与输出目录；不同题集、

## 原始测试记录

`docs/` 根目录按实验 ID 和日期保存原始报告，供逐题、逐层诊断追溯。优先从
“有效实验测试汇总”跳转，不要把单次 smoke 或不同 judge 的分数当作全量结论。

## 历史归档

[archive/](archive/README.md) 保存已被更新的状态稿、交接稿、旧计划和历史报告；
所有文件保留，不删除。`archive/restricted/` 仅本地审计，因含历史敏感信息而被
仅供本地审计，不能纳入项目移交包。

## 新增实验记录规则

1. 新建带日期的配置、输出目录和报告，避免覆盖冻结基线。
2. 报告写明题集、模型/judge、唯一变量、命令或配置、输出路径、完成时间和结论。
3. 先更新本目录的时间线/路线或有效汇总，再纳入项目移交材料。
4. 移交前按交接清单做敏感信息和大文件检查，保证材料范围清晰可复现。
