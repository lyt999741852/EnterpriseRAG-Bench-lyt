# RAG 联调控制台：开发追踪

**分支：** `codex/rag-debug-console`  
**隔离规则：** 仅提交 `rag-debug-console/` 下的文件；禁止把当前 RAG 的任何未提交变更带入本分支的提交。

## 状态定义

- `TODO`：尚未开始；设计或依赖未满足。
- `IN PROGRESS`：正在修改；不得合并或推送为完成状态。
- `DONE`：实现、测试、验收完成，且已记录提交 SHA。
- `BLOCKED`：依赖外部决策、RAG 已发布 API 或资源锁。
